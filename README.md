# Hangul Block Builder

A browser game that teaches Hangul syllable-block structure
(Neighbors, Bunk Bed, Basement, Hamburger, Corner House).

Single file, no build step, no dependencies. Fonts load from Google Fonts;
sounds are generated in the browser. Progress saves in each student's own browser (localStorage).

The page includes a `noindex, nofollow, noarchive` robots meta tag so search engines are asked not to list it.
This is a request, not a lock: anyone with the link can still open the game.

## Put it on GitHub Pages
1. Create a repository (or use an existing one) and upload `index.html` to the root
   (or to a folder, e.g. `hangul/index.html`).
2. Repo Settings > Pages > Build and deployment > Deploy from a branch > choose `main` and `/ (root)`.
3. After a minute your game is live at `https://YOUR-USERNAME.github.io/YOUR-REPO/`
   (add the folder name if you used one).
